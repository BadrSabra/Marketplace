**API endpoints & expected shapes** (agent MUST verify actual backend response; if mismatch, log and adapt code):

- `GET /api/driver/tasks`
  - Expected response: `Array<DriverTask>`
  ```ts
  type DriverTask = {
    subOrderId: string;
    store: { id: string; name: string; logoUrl?: string };
    items: { productId: string; name: string; qty: number; price: string }[];
    deliveryAddress: string;
    status: "READY" | "ASSIGNED" | "ON_THE_WAY" | "DELIVERED" | "CANCELLED";
    otpId?: string;
    assignedAt?: string;
    estimatedDistance?: number;
  }

GET /api/delivery/offers/available
Expected: Array<Offer>
type Offer = {
  id: string;
  subOrderId: string;
  store: { id: string; name: string; logoUrl?: string };
  subtotal: string;
  pickupAddress?: string;
  createdAt: string;
}

POST /api/delivery/offers (place bid)
Body: { subOrderId: string, bidAmount: string }
Response: { success: boolean, offerId?: string, error?: string }
POST /api/delivery/offers/:id/respond
Body: { action: "accept" | "reject" } (if backend expects different, adapt based on actual endpoint)
POST /api/delivery/otp/verify/:otpId
Body: { otpCode: string }
Response: { success: boolean, message?: string }
GET /api/driver/wallet
Response: { balance: string, currency?: string }
GET /api/driver/wallet/transactions?page=1&limit=20
Response: { transactions: Transaction[], total: number }
type Transaction = { id: string; amount: string; type: "CREDIT" | "DEBIT"; reference?: string; createdAt: string; }

Implement TanStack Query hooks in client/src/hooks/use-driver.ts:

useAvailableOffers()

useVerifyOtp() (mutation)
useDriverWallet()
useWalletTransactions(page)
Set default query options:

retry: 1,

Log each fetch result to console with a prefix: e.g., DRIVER_TASKS_FETCH: success, count = X.
