3. Add Arabic translations to translation_static.json if missing.
4. Fix RTL issues:
   - Tailwind directional classes: pl- → pr-, pr- → pl-, ml- → mr-, mr- → ml-
   - text-left → text-right, left- → right-, right- → left-
   - Swap directional icons (ArrowRight ↔ ArrowLeft) where needed
   - Adjust tables, selects, checkboxes, buttons, toast positions to match RTL
5. Map any backend toast keys to Arabic equivalents from toast_messages
6. Ensure the page compiles and runs after changes
7. Save a checkpoint: `Arabic RTL – <Page Name> Completed`
