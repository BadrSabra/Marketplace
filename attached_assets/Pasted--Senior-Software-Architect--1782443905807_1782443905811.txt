أنت مهندس برمجيات أول (Senior Software Architect) وخبير في تحليل المنتجات البرمجية.

أريد منك تحليل المشروع الحالي بالكامل دون تعديل أي ملف أو كتابة أي كود جديد.

المطلوب هو قراءة المشروع كاملاً ثم إنشاء تقرير تفصيلي للغاية يوضح كل ما يحتويه المشروع.

قم بفحص:

1- هيكل المشروع بالكامل
- جميع المجلدات
- جميع الملفات
- وظيفة كل مجلد
- وظيفة كل ملف
- العلاقات بين الملفات

2- التقنيات المستخدمة
- لغة البرمجة
- Framework
- قواعد البيانات
- ORM
- APIs
- المكتبات الخارجية
- خدمات الطرف الثالث
- أدوات البناء
- أدوات الاختبار
- أدوات النشر

3- معمارية النظام
- Architecture Pattern
- طبقات المشروع
- تدفق البيانات
- طريقة الاتصال بين Frontend و Backend
- إدارة الحالة
- Dependency Injection إن وجد
- Middleware
- Authentication Flow

4- قاعدة البيانات
استخرج جميع الجداول مع:
- اسم الجدول

24- في النهاية أنشئ جدولاً بعنوان:

يشمل:

مع نسبة الإنجاز لكل جزء.

مهم جداً:

- لا تكتب أي كود.
- لا تعدل أي ملف.
- لا تحذف أي شيء.
- لا تنشئ ملفات جديدة إلا إذا احتجت لإنشاء تقرير داخل مجلد docs/.
- إذا كانت بعض المعلومات غير واضحة، فاذكر أنها غير موجودة أو غير قابلة للاستنتاج، ولا تفترض أو تخمن.
- اجعل التقرير احترافياً ومفصلاً بحيث يمكن استخدامه كوثيقة رسمية لفهم المشروع بالكامل قبل تطويره أو تسويقه.
