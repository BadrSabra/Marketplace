Task: Build a Production-Ready Public Landing Page for the Hyperlocal Marketplace.

Context:
The platform is a hyperlocal marketplace serving:
- قرية ميت جابر
- القرى المجاورة فقط

This page will replace the current Customer Dashboard and become the real public homepage of the platform.

The homepage must be accessible without authentication.

====================================================
GLOBAL ARCHITECTURE RULES
====================================================

- Route: "/"
- Public page (NO authentication required)
- Do NOT modify existing auth system
- Do NOT modify database schema
- Do NOT break admin/store dashboards

====================================================
1) NAVIGATION BAR (Top Header)
====================================================

Create a clean responsive Navbar:

Left:
- Platform Logo (clickable → "/")

Center:
- Navigation links:
  - السوق
  - كيف يعمل
  - تسجيل متجر

Right:
- If NOT logged in:
  - زر "تسجيل الدخول"
  - زر "إنشاء حساب"

- If logged in:
  - Avatar dropdown
  - رابط "حسابي"

Make Navbar sticky and mobile responsive.

====================================================

"سوق ميت جابر"

"اطلب من متاجر قريتك والقرى المجاورة بسهولة وأمان"

  "خدمة محلية داخل ميت جابر فقط"

3) HYPERLOCAL NOTICE SECTION
====================================================

Small highlighted banner:
"نخدم حالياً قرية ميت جابر والمناطق المجاورة فقط"

This clarifies service scope.

====================================================
4) STORES GRID SECTION
====================================================

Create API:

GET /api/public/stores?page=1&limit=12

Backend rules:
- Return only approved stores
- Return only active stores
- Sort by newest
- Implement pagination

Response fields:
{
  id,
  name,
  description,
  logoUrl,
  isOpen,
  createdAt
}

====================================================
5) StoreCard Component
====================================================

Each card must contain:

- Logo (fallback image if null)
- Store name
- Short description (truncate 100 chars)
- Badge:
    - مفتوح
    - مغلق
- Button:
    "عرض المتجر"

On click:
Navigate to:
"/store/:id"

====================================================
6) STORE PAGE (Public)
====================================================

The store page must:

- Fetch products dynamically

If user clicks:
"إضافة للسلة"

→ Redirect to /login
