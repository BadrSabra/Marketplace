# 11 — Risk Register
**سجل المخاطر الكامل**

---

## مقياس التقييم

| الاحتمال | الأثر | = | الأولوية |
|---------|-------|---|---------|
| عالٍ × عالٍ | | = | 🔴 Critical |
| عالٍ × متوسط أو متوسط × عالٍ | | = | 🟠 High |
| متوسط × متوسط | | = | 🟡 Medium |
| منخفض × أي | | = | 🔵 Low |

---

## 🔴 Critical Risks

### R-001: فقدان بيانات الملفات
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | ملفات uploads/ مخزنة محلياً على الخادم، أي إعادة نشر أو crash تُفقد الصور والإيصالات والرخص |
| **الاحتمال** | عالٍ (عند أي deployment) |
| **الأثر** | عالٍ جداً (فقدان بيانات عملاء، خسارة ثقة) |
| **التخفيف** | ترحيل فوري إلى Cloud Storage (S3/Cloudinary) قبل أي عميل حقيقي |
| **المسؤول** | Backend Engineer |
| **الحالة** | 🔴 مفتوح |

### R-002: JWT لا يُلغى عند تسجيل الخروج
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | JWT صالح لـ 7 أيام ولا يوجد blacklist — حساب مسروق لا يمكن تعطيله |
| **الاحتمال** | متوسط |
| **الأثر** | عالٍ (اختراق حسابات) |
| **التخفيف** | Redis JWT Blacklist + Refresh Token mechanism |
| **المسؤول** | Security Engineer |
| **الحالة** | 🔴 مفتوح |

### R-003: Data Isolation كسر في Multi-tenant
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | عند تطبيق multi-tenant، bug في RLS يُظهر بيانات tenant لـ tenant آخر |
| **الاحتمال** | متوسط (خلال migration) |
| **الأثر** | حرج جداً (data breach، مسؤولية قانونية) |
| **التخفيف** | اختبار RLS صارم في Staging، Data Isolation Tests تلقائية قبل Production |
| **المسؤول** | Senior Architect + QA |
| **الحالة** | 🟡 مستقبلي (شهر 4) |

## 🟠 High Risks

### R-004: Socket.IO يفشل عند Multi-instance
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | Socket.IO بدون Redis Adapter — إذا شُغّل أكثر من instance، الرسائل لا تصل للمستخدمين على instances مختلفة |
| **الاحتمال** | عالٍ (عند أي Scale) |
| **الأثر** | متوسط (تعطل Chat) |
| **التخفيف** | Redis Adapter مع v1.1.0 |
| **المسؤول** | Backend Engineer |
| **الحالة** | 🟠 مفتوح |

### R-005: DB Migration خاطئة تحذف بيانات
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | Migration script خاطئ (خاصةً عند إضافة tenant_id) قد يحذف بيانات |
| **الاحتمال** | منخفض |
| **الأثر** | عالٍ جداً |
| **التخفيف** | DB Backup قبل كل Migration، اختبار Staging أولاً، Rollback script جاهز |
| **المسؤول** | DBA + Senior Backend |
| **الحالة** | 🟡 تحت السيطرة |

### R-006: Payment Gateway Integration فشل
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | Stripe webhook غير مُعدّ صحيحاً → transactions لا تُؤكَّد → مشاكل مالية |
| **الاحتمال** | متوسط |
| **الأثر** | عالٍ (خسارة مالية) |
| **التخفيف** | اختبار شامل في Stripe Test Mode، Idempotency keys لجميع الـ webhooks |
| **المسؤول** | Backend Engineer |
| **الحالة** | 🟠 مفتوح |

### R-007: Google Maps تكلفة عالية
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | Google Maps API قد يكون مكلفاً عند Scale ($7/1000 requests) |
| **الاحتمال** | متوسط |
| **الأثر** | متوسط (تكلفة غير متوقعة) |
| **التخفيف** | استخدام OpenStreetMap (Leaflet) مجاناً، أو تحديد Budget Alert |
| **المسؤول** | CTO |
| **الحالة** | 🟡 للمراجعة |

## 🟡 Medium Risks

### R-008: Rate Limiter يحجب مستخدمين شرعيين
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | مستخدمون خلف shared IP (شركة أو ISP) يُحجبون بسبب الـ Rate Limiter |
| **الاحتمال** | منخفض |
| **الأثر** | متوسط (تجربة سيئة) |
| **التخفيف** | استخدام User ID بدلاً من IP للـ authenticated endpoints |
| **المسؤول** | Backend Engineer |
| **الحالة** | 🟡 مراقبة |

### R-009: Push Notifications لا تصل على بعض Browsers
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | iOS Safari لديه قيود على Web Push (قبل iOS 16.4) |
| **الاحتمال** | عالٍ لمستخدمي iOS |
| **الأثر** | منخفض (fallback لـ in-app notifications) |
| **التخفيف** | Fallback لـ polling + In-App Bell دائماً موجود |
| **المسؤول** | Frontend Engineer |
| **الحالة** | 🟡 مراقبة |

### R-010: تقنية الدين التقني يبطئ التطوير
| الحقل | التفاصيل |
|-------|---------|
| **الوصف** | routes.ts الضخم + غياب Tests يجعل إضافة ميزات أبطأ ويزيد الـ bugs |
| **الاحتمال** | عالٍ |
| **الأثر** | متوسط (إبطاء التطوير) |
| **التخفيف** | تقسيم routes.ts في Sprint 1، Tests في Sprint 1-2 |
| **المسؤول** | Senior Architect |
| **الحالة** | 🟠 مفتوح |
